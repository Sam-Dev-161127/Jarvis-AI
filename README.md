# Jarvis-AI

Jarvis-AI is a desktop voice assistant built using Python. It can understand and respond to voice commands to perform everyday tasks on the computer.

It uses the Gemini AI API to generate intelligent, human-like responses during conversations. The assistant can open websites, launch applications, play songs, and perform system actions based on user commands.

The project is designed in a modular way, so new features like weather updates, news, automation tools, or smart integrations can be added easily in the future.

---

## ✨ Features

- 🎤 Voice-based command recognition  
- 🤖 AI-powered responses using Gemini API  
- 🌐 Open websites using voice commands  
- 🎮 Launch applications and games  
- 🎵 Play songs from local storage  
- 📅 Tell date, day, month, year, and current time  
- 🧩 Modular structure for easy feature expansion  

---

## 🛠️ Technologies Used

- Python  
- SpeechRecognition  
- Google Gemini API  
- Webbrowser module  
- OS module  
- Datetime module  

---

## ⚙️ How it works

1. User gives a voice command  
2. Jarvis processes the speech  
3. Command is interpreted using programmed logic or Gemini AI  
4. Action is executed (open app, website, play song, or respond)
