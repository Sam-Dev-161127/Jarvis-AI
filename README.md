# Jarvis-AI

Jarvis-AI is a desktop voice assistant built using Python. It can understand and respond to voice commands to perform everyday tasks on the computer.

It uses the OpenAI API to generate intelligent, human-like responses during conversations. The assistant can open websites, launch applications, and perform system actions based on user commands.

The project is designed in a modular way, so new features like weather updates, news, or other API-based tools can be added easily in the future.

---

## Features

- Voice-based command recognition  
- AI-powered responses using OpenAI API  
- Open websites using voice commands  
- Launch applications on the system  
- Modular structure for easy feature expansion  

---

## How it works

1. User gives a voice command  
2. Jarvis processes the speech  
3. Command is interpreted using AI logic  
4. Action is executed (open app, website, or respond)
